גרסה עצמאית של LiveContainer + SideStore עם ממשק מאוחד לאפליקציות אורחות, חתימה, התקנה ורענון במכשיר.

השימוש הרגיל מתבצע דרך **Home / Apps / Sources / Refresh / Settings**. להתקנה ולצימוד הראשוניים נדרש מחשב. מסלול הרענון הנתמך דורש **Wi-Fi ואת LocalDevVPN הרשמי**. אין הבטחה לרענון דרך חיבור סלולרי בלבד.

זו אינה גרסה רשמית של [LiveContainer](https://github.com/LiveContainer/LiveContainer) או [SideStore](https://github.com/SideStore/SideStore).

<a id="installation"></a>
## התקנה

נדרשים iPhone או iPad נתמך, מחשב, חשבון Apple לחתימה, נתוני צימוד למכשיר המסוים ו-[iLoader בגרסה 2.3.1 ומעלה](https://github.com/nab138/iloader/releases/latest) או מתקין IPA תואם.

1. הורידו את ה-IPA שלמעלה. חברו את המכשיר ב-USB, בטלו את הנעילה ואשרו אמון במחשב. ב-Windows התקינו את מנהלי ההתקנים של Apple במידת הצורך.
2. ב-iLoader בחרו את המכשיר, התחברו לחשבון Apple לחתימה ופתחו **Installers → Import IPA**. בחרו את קובץ הפרויקט, ולא את חבילת SideStore או LiveContainer הרגילה של המתקין.
3. שמרו את ההרחבות הנדרשות, כולל **LiveProcess**, והשלימו את ההתקנה כשהמכשיר מחובר ולא נעול.
4. במידת הצורך אשרו אמון במפתח תחת הגדרות iOS: **כללי → VPN וניהול מכשירים**. הפעילו **פרטיות ואבטחה → מצב מפתח** ואשרו לאחר ההפעלה מחדש.
5. ב-iLoader פתחו **Management → Manage Pairing File**, סרקו מחדש את האפליקציות אם צריך ובחרו **Place** עבור האפליקציה שהותקנה. נתוני הצימוד חייבים להשתייך למכשיר הזה בדיוק.

**קובצי צימוד מכילים פרטי גישה פרטיים למכשיר. אין לצרף אותם לדיווח תקלה, ליומן ציבורי או לצילום מסך.**

### הגדרת LocalDevVPN

התקינו את **[LocalDevVPN הרשמי](https://apps.apple.com/us/app/localdevvpn/id6755608044)** של **Coxson Engineering LLC**. אין צורך ב-VPN נוסף מסוג IKEv2/IPsec למסלול הזה.

1. בהגדרות iOS פתחו **Wi-Fi → ⓘ** ובדקו את **כתובת ה-IP** ואת **מסכת רשת המשנה**.
2. בחרו **שתי כתובות IPv4 שונות ופנויות באותה רשת משנה של ה-Wi-Fi**. אל תשתמשו בכתובת הטלפון, הנתב, המחשב או מכשיר אחר. בדקו את רשימת המכשירים או הקצאות DHCP בנתב; כישלון ping לבדו אינו מוכיח שהכתובת פנויה.
3. ב-**LocalDevVPN → Settings → Network Configuration** הזינו **Tunnel IP** ו-**Device IP**, כל אחת עם **`/32`**.
4. הפעילו **Allow Intermediate Addresses**, לחצו **Done** ואז **Save & Apply**.
5. חברו את LocalDevVPN ובדקו ב-**Session Details** שהכתובות נשמרו.

לדוגמה בלבד: ברשת `192.168.1.x` עם מסכה `255.255.255.0`, אפשר להשתמש ב-`192.168.1.240/32` וב-`192.168.1.241/32` אם הן פנויות. אין להעתיק את הכתובות בלי לבדוק את הרשת שלכם.

**אם רשת המשנה של ה-Wi-Fi משתנה, עדכנו את שתי הכתובות לפני הרענון.**

### התחברות ורענון

האימות משתמש בספק Mac anisette החיצוני `mac-ani.jkcoxson.com` ושומר את הזהות שלו ב-Keychain. זהו גבול אמון מול צד שלישי מבחינת רשת ופרטיות, ולא תהליך אימות מקומי לחלוטין. בדקו את התלות הזו לפני ההתחברות ואל תפרסמו נתוני זהות של הספק.

1. כש-Wi-Fi ו-LocalDevVPN מחוברים, פתחו באפליקציה **Settings → Account and Signing → Sign In / Authenticate**.
2. פתחו **Refresh** והפעילו רענון ידני.
3. בדקו את התוצאה הסופית בהיסטוריית הרענון ובאימות. עצם התחלת המשימה או העברתה להמשך טיפול אינן הצלחה.
4. רק לאחר רענון ידני מוצלח הפעילו רענון אוטומטי ב-**Refresh** ובחרו תזמון זמין: כל שש שעות, יומי או שבועי.
5. הפעילו רענון יישומים ברקע ב-iOS ואשרו התראות אם תרצו לקבל עדכונים על רענון ופקיעת חתימה.

לאחר ההגדרה הראשונית המחשב לא אמור להישאר מחובר למסלול הרענון הנתמך. **ההפעלה ברקע אינה מובטחת:** iOS קובעת מתי המשימות ירוצו. בדקו את הרענון המאומת האחרון לפני פקיעת החתימה. השעה שנבחרה אינה שעון מעורר מדויק.

<a id="updating-without-losing-your-setup"></a>
## עדכון בטוח

- גבו קודם נתונים חשובים של אפליקציות אורחות וקראו את [הוראות השדרוג](https://github.com/NRG-Wardog/sidestore-auto-refresh/releases/tag/v6.0.1).
- התקינו מעל אפליקציית **LiveContainer** הקיימת והתואמת, עם **אותה זהות חתימה (חשבון Apple / Personal Team) ומזהים תואמים**.
- שמרו את ההרחבות הנדרשות, כולל **LiveProcess**. אין למחוק את האפליקציה כשלב עדכון שגרתי.
- IPA של SideStore עצמאי אינו תחליף ל-IPA המשולב של LiveContainer.
- אל תאפסו נתוני חשבון, אפליקציה או צימוד כניסיון תיקון ללא אבחון.

<a id="troubleshooting"></a>
## פתרון תקלות

לפני שינוי נתונים בדקו:

- קובץ וגרסת הבנייה המדויקים, אמון במפתח, מצב מפתח והרחבות נדרשות.
- חיבור ל-LocalDevVPN הרשמי, שתי כתובות פנויות באותה רשת משנה עם `/32`, והגדרות **Allow Intermediate Addresses** ו-**Save & Apply**.
- התאמת הצימוד למכשיר והשלמת ההתחברות ב-**Account and Signing**.
- שלב הכשל המדווח: רשת/VPN,‏ CoreDevice/RSD, צימוד, אימות, חתימה או התקנה.
- אם הרענון האוטומטי לא פעל, נסו רענון ידני ובדקו את רענון היישומים ברקע ב-iOS.

בדיווח ב-[Issues](https://github.com/NRG-Wardog/sidestore-auto-refresh/issues) ציינו גרסת בנייה, דגם וגרסת iOS, פעולה שנכשלה ושגיאה קצרה ללא פרטים פרטיים. אין לצרף קובצי צימוד, פרטי התחברות, מפתחות פרטיים או יומני מכשיר שלא נוקו.
